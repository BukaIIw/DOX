# DOX MUSIC

> Liquid Glass web music player with procedural track generation,
> auto-mix by mood, and auto-skip of unavailable YouTube tracks.

![DOX MUSIC](art_balance.jpg)

## Features

- **Liquid Glass UI** — WebGL fragment shader renders a flowing metaball field with FBM noise that reacts to playback state and track energy
- **Glassmorphism** — frosted glass cards with `backdrop-filter: blur()` and soft shadows
- **Dark / Light theme** — toggle in the header, persisted in `localStorage`
- **RU / EN i18n** — full interface translation, persisted in `localStorage`
- **Auto-skip unavailable tracks** — YouTube errors `101` / `150` are caught, the track is marked with ⚠ in the playlist (greyed out) and automatically skipped on the next play. The list of blocked IDs is persisted so they don't come back.
- **Auto-Mix by mood** — each track is analyzed (preset meta for local tracks, keyword matching for YouTube tracks) and grouped by mood: `Dark`, `Energetic`, `Chill`, `Calm`. Auto-mix builds a queue with an energy curve (soft start → peak → cool-down) for seamless listening.
- **6 procedural presets** — `phonk`, `jumpstyle`, `lofi`, `ambient`, `rave`, `darktrap` generated by `gen_track.py`
- **Live track regeneration** — the "Generate new" button calls `/api/regenerate` (when served by `serve.py`) which actually runs the Python generator and produces a brand new `my_track.wav`
- **Keyboard shortcuts** — `Space`, `←/→`, `N/P`, `M`, `S`, `R`, `A` (auto-mix), `G` (regenerate), `L` (language)
- **Mobile-first responsive layout** — tested at 390×844 viewport

## Quick start

### Option A — with live regeneration (recommended)

```bash
git clone https://github.com/<you>/dox-music.git
cd dox-music
python serve.py --port 8000
# → open http://localhost:8000
```

In this mode the **Generate new** button actually invokes `gen_track.py`
and overwrites `my_track.wav` with a random preset on every click.

### Option B — static file serving

```bash
git clone https://github.com/<you>/dox-music.git
cd dox-music
python -m http.server 8000
# → open http://localhost:8000
```

In this mode the **Generate new** button cycles through the 6 pre-generated
preset tracks (no Python invocation).

## Generator usage

```bash
python gen_track.py                # Random preset → my_track.wav
python gen_track.py all            # Generate all 6 presets
python gen_track.py phonk          # Specific preset → track_phonk.wav
python gen_track.py phonk out.wav 30  # Custom output + duration (seconds)
```

Available presets: `phonk`, `jumpstyle`, `lofi`, `ambient`, `rave`, `darktrap`.

| Preset    | BPM | Mood      | Energy | Notes                              |
|-----------|-----|-----------|--------|------------------------------------|
| phonk     | 65  | Dark      | 0.55   | Saturated bass, minor pentatonic   |
| jumpstyle | 140 | Energetic | 0.85   | 4-floor kick, square-wave lead     |
| lofi      | 75  | Chill     | 0.30   | Swing, dorian scale, soft pads     |
| ambient   | 60  | Calm      | 0.10   | Beatless, evolving pads            |
| rave      | 160 | Energetic | 0.95   | Driving bass, saw-wave lead        |
| darktrap  | 70  | Dark      | 0.60   | Triplet hats, 808-style bass       |

## Auto-mix — how it works

1. Each track is analyzed:
   - **Local** — preset meta is read from `PRESET_META` in `gen_track.py`
   - **YouTube** — keywords in title/artist are matched against `MOOD_KEYWORDS` in `player.js`
2. User selects a mood chip: `All`, `Dark`, `Energetic`, `Chill`, `Calm`
3. When auto-mix starts, a queue is built with an energy curve:
   - Filter tracks by selected mood
   - Sort by energy (ascending)
   - Mirror the second half → smooth "hill" shape
4. Queue plays sequentially; transitions are smooth

## Handling unavailable YouTube tracks

YouTube IFrame API returns `101` or `150` when the rights holder has disabled
embedding. In that case:

1. Track ID is added to `localStorage.dox_blocked` array
2. Track is shown greyed-out with a ⚠ icon in the playlist
3. Clicking on it shows a "track unavailable — auto-skipped" toast
4. Playback automatically advances to the next track
5. To reset the blocked list — open DevTools console and run:
   ```js
   localStorage.removeItem("dox_blocked");
   location.reload();
   ```

## Browser support

- Chrome / Edge 100+
- Firefox 103+
- Safari 15.4+ (backdrop-filter requires 15.4+)
- Requires WebGL for the liquid glass background (CSS fallback otherwise)

## Tech stack

- **Frontend**: Vanilla JS (no build step), CSS custom properties, WebGL 1
- **Backend** (optional): Python 3 stdlib `http.server` + `subprocess`
- **Generator**: Python 3 stdlib only (`wave`, `struct`, `math`, `random`)
- **External**: YouTube IFrame API, Google Fonts (Inter + Manrope)
